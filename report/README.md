# Project Report

This folder contains the complete technical report for the anomaly detection project.

The report presents the methodology, experimental setup, results, and comparison of supervised and unsupervised approaches for anomaly detection in network traffic using the CICIDS2017 dataset.

The evaluated models include:

- Logistic Regression
- Random Forest
- Isolation Forest
- Autoencoder
